# Знаки компонентов

- `ffmpeg.ico` — оригинальный значок FFmpeg из [официального сайта](https://ffmpeg.org/favicon.ico), набор размеров до 64×64. Байты сохранены без изменения.
- `onnx-runtime.svg` — квадратный знак из шапки [официального сайта ONNX Runtime](https://onnxruntime.ai/), `viewBox="0 0 694 694"`. Геометрия и цвета сохранены; namespace заменён с https на корректный для самостоятельного SVG http.

Получены 3 ноября 2026 года. Знаки используются для обозначения соответствующих компонентов, загружаются из локальной сборки и не требуют сети. Размер задаёт единая область карточки, пропорции сохраняются. Для моделей и словаря используются нейтральные значки MUI; логотип площадки хранения не выдаётся за логотип модели.
