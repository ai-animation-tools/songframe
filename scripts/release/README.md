# Инструмент выпуска SongFrame

`release.mjs` управляет подготовкой и публикацией локально собранного выпуска. Его запускает `yarn release` из корня репозитория. Команды `plan`, `prepare` и `publish`, требования к версии и состав комплекта описаны в [руководстве разработчика](../../docs/development.md#выпуск-релиза); это источник порядка выпуска.

`release.test.mjs` проверяет Git-состояние, восстановление загрузки, сохранность файлов и сверку вложений через подменённый GitHub. Тесты используют временные репозитории и маленькие тестовые поставки, без сети, сборки настоящих пакетов и публикации:

```sh
yarn test:release
```

Изменения только этой папки и сопровождающей документации получают [адресный job CI](../ci/README.md): lint, форматирование и тесты инструмента выпуска. Проверки приложения, Python-инструментов и браузерных историй для такого изменения не запускаются.

Для адресного job CI команда `yarn install --immutable --mode=skip-build` устанавливает JavaScript-зависимости без выполнения install-скриптов и загрузки Electron. ESLint, Prettier и тесты сценария работают на Node; сборка поставок использует обычную установку зависимостей.
