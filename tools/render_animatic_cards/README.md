# render_animatic_cards

Служебный рендерер условных PNG-карточек из реестра и существующих референсов. Прямого CLI нет: карточки и их манифест обновляет [update_scene_views](../update_scene_views/README.md).

## Контракт

Входы: `plan/scenes.json`, изображения `source/`, системные шрифты DejaVu и Pillow. `render_card` вызывается из общего обновления; отдельный скрипт для партии не нужен. Карточка не является сгенерированным опорным кадром или готовой сценой. Полную сборку выполняет [build_animatic](../build_animatic/README.md).

`render_keyframe_card(shot, target, project, keyframes, root, last_target)` рисует карточку плана, у которого все опоры пакета приняты: первая опора целиком на холсте, остальные полоской внизу, подпись «опоры приняты, видео не сгенерировано». При двух и более опорах последняя сохраняется отдельным PNG `Mxx.last.png` для растворения в сборке. Опоры вписываются без обрезки и растяжения.

`render_card(shot, target, project, references, root)` получает контекст явно: название из `plan/project.json`, референсы из `scenes.json`, корень для чтения изображений. Подпись миниатюры берётся из `short_name`, при отсутствии — из `name`. Глобальный реестр при импорте не загружается. После изменения проектных данных запускать общий обновитель; вручную заменять PNG не нужно.
