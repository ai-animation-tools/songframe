# asset_package

Проверяет один комплект сцены или воспроизводит её принятый монтаж. Использовать при переносе в assets, проверке сохранности или порученном восстановлении обработки.

## Контракт

```sh
python3 -B tools/asset_package/asset_package.py M31
python3 -B tools/asset_package/asset_package.py M31 --output /tmp/M31-copy.mp4
python3 -B tools/asset_package/asset_package.py M31 --output /tmp/M31-rebuilt.mp4 --from-original
```

Во всех режимах проверяются локальный манифест, SHA-256 всех его файлов, включая общие изображения из `source`, наличие Mxx в текущем `plan/scenes.json`, совпадение FPS и числа кадров с разностью `end_frame_exclusive − start_frame`. Это проверка JSON и хешей без `ffprobe` и декодирования; без `--output` ничего не записывается.

`root: "source"` разрешён только для входных изображений и референсов подготовки, путь отсчитывается от `source`; остальные файлы остаются в папке сцены. `descriptor_file(directory, item, root=None)` разрешает такой дескриптор для других инструментов; `root` задаёт корень проекта и обычно не передаётся.

У `kind: "derived_video"` обязателен снимок происхождения `generation.source_scene_sha256` (SHA либо явный `null` для исторически неизвестной постановки) и `source_accepted_video_sha256` выбранного исходного клипа. Проверка этого контракта не требует доступности сегодняшнего источника: сохранённая локальная копия сохраняет воспроизведение даже у `stale`.

`accepted_edit.repeat`, если задан, содержит только целые `full_cycles`, `tail_frames`, `cycle_frames`: положительную длину цикла, полные циклы и хвост короче цикла. Их сумма в кадрах должна равняться `accepted_edit.frames`.

`--output` копирует точные принятые байты. `--from-original` повторяет стадии FFmpeg: сохраняет обработку и кадровую длину, но не обещает побайтово одинаковый H.264. Выход — новый файл вне assets; оригинал и выбранный клип не меняются. [Контракт комплекта](../../templates/project/assets/README.md#локальный-манифест-и-воспроизведение).

## Тесты

Технический контракт комплекта, монтажное окно и FPS по текущему реестру, общие референсы без локальной копии, обнаружение их изменения/удаления, ограничения корней и воспроизведение принятого монтажа.

```sh
python3 -B tools/asset_package/test_asset_package.py
python3 -B tools/run_tests/run_tests.py --only test_asset_package
```

Тесты находятся рядом со скриптом; рабочие сцены не изменяют, временные результаты создают вне проекта. Для полного набора — [run_tests](../run_tests/README.md).
