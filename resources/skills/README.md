# Промпты заданий агента

Источники инструкций для заданий Claude Code или Codex, которые запускает приложение. Клип ведётся кнопками приложения; эти файлы не являются навыками для ручного запуска агента в папке клипа и не устанавливаются в проекты. Задания работают в режиме предложения (`output=proposal`): агент получает инструкции и контекст через stdin, возвращает один JSON и не записывает файлы, не вызывает shell и инструменты. Проверку, показ, применение предложения, согласования, генерацию медиа и платную отправку ведёт приложение.

| Файл | Кто читает | Назначение |
| --- | --- | --- |
| [ai-clip-video-review/SKILL.md](ai-clip-video-review/SKILL.md) | `internal/videoreview` передаёт инструкцию, постановку и настоящие изображения кадров и опор | Отчёт о соответствии, расхождениях и неопределённостях с таймкодами; без принятия видео |
| [ai-clip-scenario/SKILL.md](ai-clip-scenario/SKILL.md) | `internal/scenarioworkflow` вкладывает файл целиком в промпт прохода `treatment`, `scenes` или `revise` | Кастинг и трактовка, заполнение реестра сцен, доработка выбранных планов; правила состояния героев |
| [ai-clip-scene/SKILL.md](ai-clip-scene/SKILL.md) | `internal/productionworkflow` склеивает три файла `ai-clip-scene` в промпт этапа `description`, `prompt` или `request` | Контекст задания, непрерывность, длительность и опоры, выбор модели и входов, речевые планы |
| [ai-clip-scene/references/app-proposal.md](ai-clip-scene/references/app-proposal.md) | то же | JSON-контракт ответа каждого этапа |
| [ai-clip-scene/references/prompt-template.md](ai-clip-scene/references/prompt-template.md) | то же | Каркас промптов опор и видеопромпта |

Формат ответа и ограничения, которые проверяет приложение, дополнительно задаёт сам код в конце промпта. Особенности конкретных сервисов генерации в эти файлы не входят: к промпту этапа производства приложение добавляет раздел «Указания агенту» из документа выбранного провайдера `resources/providers/<вид>/<id>.md` (`providers.Guide`). Имена скиллов заданы константами `resources/resources.go`, SHA-256 файлов закреплены в `resources/resources_test.go` и эталонах промптов `testdata/golden`: при переименовании или правке меняйте их вместе. Папка встроена в бинарник (`//go:embed skills`).

Фронтматтера у файлов нет: это обычный markdown, вкладываемый в промпт. Ссылки между файлами относительные; агенту они не нужны для работы, поскольку все три файла `ai-clip-scene` уже переданы в одном промпте.
