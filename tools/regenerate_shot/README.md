# regenerate_shot

Повтор генерации плана по сохранённому запросу без нового согласования опор и промпта. Использовать по аргументу `regenerate=true` скилла `ai-clip-scene` или кнопкой «Перегенерировать» в приложении, когда опоры и промпт устраивают, а результат нет. Конкретное явное поручение пользователя `regenerate=true` разрешает одну новую попытку показанного сохранённого запроса по проверенной цене. Вызов скрипта агентом сам по себе такого разрешения не даёт; стоимость и баланс проверяются перед отправкой, следующие повторы согласуются отдельно.

## Контракт

```sh
python3 -B tools/regenerate_shot/regenerate_shot.py M32
python3 -B tools/regenerate_shot/regenerate_shot.py M32 --submit
python3 -B tools/regenerate_shot/regenerate_shot.py M32 --source asset --json
```

- Источник запроса (`--source auto` по умолчанию): сначала последний пакет плана в `plan/batches` или `plan/awaiting` с подготовленной попыткой (`request_dir/request.json`), затем снимок принятого комплекта `assets/shots/Mxx/generation-request.json`, если он записан комплексом в формате замороженного запроса (`provider`, список `inputs` со слотами, файл промпта). Снимки старого формата, другие провайдеры и отсутствие данных останавливают инструмент с кодом 3 и сообщением; значения не придумываются.
- Создаётся новый пакет `plan/batches/Mxx-attempt-NN` (`shot_workflow init`, `retry_of` указывает на исходный пакет) и попытка `request/` через `kling_request prepare` с теми же входами, промптом, моделью и параметрами. Этап пакета `request_choice`. Перед этим запрос сверяется с блоком `generation` в `plan/project.json`: другой провайдер, разрешение или пропорции останавливают повтор.
- Выводятся `request_sha256`, модель, параметры, число входов, длина промпта и таблица `cost_check` (остаток запрашивается у аккаунта, `--no-account` отключает).
- `--submit`: ровно одна отправка `kling_request submit --confirm`, запись расхода `cost_check learn`, этап `submitted`, одно ожидание `watch` (`--max-minutes`, по умолчанию 20) и этап `downloaded` при успехе. При вердикте `insufficient_balance` или `cost_or_balance_unknown` отправка не выполняется. Техническую сводку делает `contact_sheet --package` отдельно.
- `--cli` подменяет исполняемый файл Kling, `--pricing` файл тарифов (тесты и прогоны без расхода: наблюдения не попадают в общий `pricing.json`). `--json` печатает одну строку JSON со сведениями пакета, стоимостью и состоянием попытки.

## Тесты

Подставной CLI без сети: отказ без данных, повтор из пакета с отправкой и получением, повтор из снимка комплекта, остановка при расхождении с настройками проекта.

```sh
python3 -B tools/regenerate_shot/test_regenerate_shot.py
```
