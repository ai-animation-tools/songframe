# animatic_cache

Служебный модуль кэша производных без собственного CLI: `ArtifactCache` связывает рецепт и входные хеши с файлом и квитанцией. Для работы запускать [build_animatic](../build_animatic/README.md); прямой вызов модуля не требуется. Новые данные проекта здесь не хранить. [Тест](#тесты).

## Хранение и очистка кэша

Производные видеофрагменты находятся в `plan/animatic/.cache/segments`; папка исключена из Git. Для готовой сцены входом служит принятый монтажный клип, для неготовой — PNG из `plan/animatic/cards`. Ключ включает SHA-256 входа, число кадров, тип входа, нормализацию формата, параметры кодирования и полную версию FFmpeg.

Готовая запись имеет квитанцию с размером и SHA-256. Повреждённая производная или прерванная запись пересоздаётся; новая запись публикуется только после проверки. Изменение одной сцены или карточки пересоздаёт только её фрагмент. Остальные соединяются копированием видеопотока, песня накладывается один раз.

Кэш не является источником сцены и не содержит обязательной истории; его можно удалить целиком, это влияет только на скорость: повторная сборка из исходных входов даёт тот же результат в той же среде кодирования. Правила полной сборки — в [описании аниматика](../../templates/project/plan/animatic/README.md).

## Тесты

Повреждённые и прерванные записи кэша не переиспользуются.

```sh
python3 -B tools/animatic_cache/test_animatic_cache.py
python3 -B tools/run_tests/run_tests.py --only test_animatic_cache
```

Тесты находятся рядом со скриптом; рабочие сцены не изменяют, временные результаты создают вне проекта. Для полного набора — [run_tests](../run_tests/README.md).
