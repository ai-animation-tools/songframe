# build_review

Длительность песни проверяется по декодированному звуку в той же шкале, что и разметка; начальная метка контейнера MP3 не вычитается из длины трека.

Собирает порученную временную видеопробу из соседних сцен, рабочего ролика и карточек. Использовать для оценки генерации и стыков; проба не является полным аниматиком или принятием сцены.

## Контракт

```sh
python3 -B tools/build_review/build_review.py --shots M30 M31 M32 --output plan/batches/M31-review/review.mp4 --plan-only
python3 -B tools/build_review/build_review.py --shots M30 M31 M32 --output plan/batches/M31-review/review.mp4
python3 -B tools/build_review/build_review.py --spec /tmp/review.json --output plan/batches/M31-review/review.mp4
```

`--shots` берёт `accepted_edit.video` готовой сцены, для сцены без комплекта — актуальную карточку по имени Mxx; повреждённый готовый клип карточкой молча не заменяется, оригинал генерации вместо принятого монтажа автоматически не используется. `--spec` задаёт рабочий ролик, обрезку, скорость, удержания и переходы по [формату JSON](spec-format.md); `--shots` и `--spec` взаимоисключающи. `--plan-only` проверяет параметры и медиа, выводит рецепт без кодирования и записи.

Монтажная сетка — 30 FPS после преобразования входа; начало включительно, конец исключительно. Пропорции сохраняются, при необходимости добавляются поля. Музыка — непрерывный участок `source/track.mp3` с канонической границы первой сцены; звук роликов не подмешивается. Состав пробы, изменения участка, скорости и переходов должны входить в поручение; подготовленный JSON сам по себе сборку не разрешает.

Конец песни округляется к ближайшему кадру 30 FPS. Если кадровая граница оказывается чуть позже конца аудио, только этот остаток (не более половины кадра) дополняется тишиной; видео и положение музыки не меняются. Реальная нехватка песни сверх округления останавливает сборку. Точный аудиофильтр сохраняется в `audio.filter` рецепта пробы.

Выходы: MP4 и одноимённый JSON с входами, хешами, обработкой, стыками и звуком. Путь — только `plan/batches` или `/tmp`, существующий результат не перезаписывается. Чего проба не меняет и как хранить её после принятия — [AGENTS.md](../../AGENTS.md).

## Тесты

Обрезка на сетке 30 FPS, исходники 24 FPS, скорость, удержания, переходы и повторяемость видео.

```sh
python3 -B tools/build_review/test_build_review.py
python3 -B tools/run_tests/run_tests.py --only test_build_review
```

Тесты находятся рядом со скриптом; рабочие сцены не изменяют, временные результаты создают вне проекта. Для полного набора — [run_tests](../run_tests/README.md).
