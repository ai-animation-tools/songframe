# Правила интерфейса SongFrame

Этот раздел — рабочий стандарт для новых экранов и изменений существующего интерфейса. Перед изменением страницы или общего компонента прочитайте относящиеся к задаче правила. При противоречии с правилами репозитория действует [AGENTS.md](../../AGENTS.md); предметные требования конкретного рабочего процесса остаются в документации этого процесса.

- [Темы и палитра](theme.md) — действующие цвета, типографика, отступы и применение смысловых цветов.
- [Структура фронтенда](structure.md) — страницы, компоненты, общие модули и границы процессов Electron.
- [Компоновка и элементы управления](layout.md) — порядок областей, расположение действий, формы, состояния и адаптация.

Значения, явно заданные в коде темы, описаны как существующие. Правила компоновки — единый ориентир для дальнейшей работы: отдельные существующие экраны могут пока им не соответствовать. Этот документ сам по себе не означает, что все страницы уже переработаны. При изменении страницы приводите затронутые элементы к правилам в пределах задачи, не меняя соседние сценарии без необходимости. Если предметный процесс требует исключения, объясните его в изменении и сохраните единообразие внутри этого процесса.

Приложение работает с медиа и потенциально дорогими или необратимыми операциями. Компоновка должна помогать понять текущий объект, его состояние, следующее действие и последствия; она не заменяет существующие правила сохранения, согласования и подтверждения платных запросов.
