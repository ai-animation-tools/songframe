# cost_check

Оценивает стоимость подготовленного запроса и сверяет с остатком кредитов до показа таблицы запроса. Использовать по скиллу перед вопросом «отправить или сохранить?» и при продолжении отложенного пакета. Инструмент не отправляет генерацию; единственное обращение к сервису — информационная команда `kling account`.

```sh
python3 -B tools/cost_check/cost_check.py check --work-dir plan/batches/M32-attempt-01
python3 -B tools/cost_check/cost_check.py check --request /tmp/request.json --balance 1824 --no-account
python3 -B tools/cost_check/cost_check.py check --work-dir plan/awaiting/M32/request --json
python3 -B tools/cost_check/cost_check.py learn --work-dir plan/batches/M32-attempt-01
```

`check` читает замороженный `request.json` попытки или спецификацию до подготовки, берёт тариф из [pricing.json](pricing.json), остаток — из ответа `account` (сохраняется только число и имя поля, не весь ответ) или из `--balance`, и печатает таблицу с вердиктом: `ok`, `insufficient_balance`, `cost_or_balance_unknown`. Названия вердиктов совпадают с причинами ожидания в [README очереди](../../templates/project/plan/awaiting/README.md). Код возврата 2 при любом вердикте кроме `ok`, чтобы скилл не мог пропустить проверку молча.

`account` использует общий `tools/kling_cli.py`, как отправка и получение: приложение передаёт встроенный официальный CLI через `SONGFRAME_KLING_EXECUTABLE` и `SONGFRAME_KLING_SCRIPT`, отдельный Node.js не нужен. Electron-режим включается только у дочернего CLI. Явный `--cli <файл>` имеет приоритет; вне приложения без этих переменных используется внешний `kling` из PATH. Отсутствующий встроенный комплект даёт неизвестный остаток с пояснением, без скрытой подмены глобальным CLI.

Таблица цен заполняется вручную по кабинету Kling: для видео — `per_second` по уровням разрешения и `base_credits` за запрос, для изображений допустим явно заданный `per_image`. `null` означает «неизвестно», и вердикт становится `cost_or_balance_unknown` с объяснением. `learn` после отправки записывает фактический `credits_consumed` из `attempt.json` как наблюдение. Для видео сохраняется прежняя оценка по наблюдению того же тарифа: точная по длительности либо пересчитанная по секундам.

Для изображения `learn` сохраняет `kind=image`, модель, `command`, `img_resolution`, `quality`, число результатов и `image_signature`. Подпись — canonical JSON с командой, полным JSON параметров, `outputs` и упорядоченными `flag`/`slot` каждого входа. Текст промпта и поля авторизации исключены; пути, хеши, размеры референсов и локальная подпись `role` не задают тариф. Порядок ключей JSON не влияет на совпадение; число входов и фактические слоты CLI учитываются.

Оценка изображения использует фактический **общий** расход только для точно такой же подписи и модели, даже если отдельной записи `models[model]` нет. Наблюдение T2I не переносится на I2I, `1k` на `4k`, `low` на `high`, один результат на девять или один референс на несколько. Любой новый параметр тоже требует своего наблюдения. Старое наблюдение изображения без подписи не подтверждает точную цену. При отсутствии совпадения и ручного `per_image` цена остаётся неизвестной; `learn` не создаёт универсальный тариф за изображение. В таблице image-запроса показываются `command`, `img_resolution` и `quality`, без видеодлительности.

## Тесты

Оценка по таблице и по наблюдениям, неизвестная цена, остаток из подставного `account`, общий префикс встроенного CLI, только дочерний Electron-режим, приоритет явного CLI и отказ при отсутствующем комплекте, ручной остаток, вердикты и запись наблюдения. Для изображений проверяются точная конфигурация без отдельной записи модели, различия команды/разрешения/quality/числа результатов/референсов, canonical JSON без промпта и секретов, общий расход без видеопересчёта и image-поля таблицы.

```sh
python3 -B tools/cost_check/test_cost_check.py
python3 -B tools/run_tests/run_tests.py --only test_cost_check
```

Тесты находятся рядом со скриптом; к сервису не обращаются, временные таблицы цен создают вне проекта. Для полного набора — [run_tests](../run_tests/README.md).
