# export_edit_bundle

Собирает пакет для монтажёра из реестра сцен, манифестов assets и разметки песни: таблицу планов с таймкодами песни и выбранными участками оригиналов, EDL, FCPXML с точной шкалой аниматика, строки песни, машиночитаемый `bundle.json` и README пакета. Использовать при передаче материалов на финальный монтаж и для контрольных сборок; assets и реестр не изменяются.

```sh
python3 -B tools/export_edit_bundle/export_edit_bundle.py --out /tmp/sample-edit-bundle
python3 -B tools/export_edit_bundle/export_edit_bundle.py --out /tmp/sample-edit-bundle --copy
python3 -B tools/export_edit_bundle/export_edit_bundle.py --out plan/batches/edit-bundle-v01 --copy
```

Папка пакета должна быть пустой и находиться вне папки проекта либо внутри `plan/batches`. Без `--copy` пути в таблицах относительны к корню папки проекта; с `--copy` в `media/` копируются оригиналы генераций, принятые клипы, входы рецептов, кадры-опоры, промпты, снимки запросов, WAV и рецепты липсинка, карточки неготовых планов, общие референсы и песня, а пути переписываются относительно пакета. Хеши SHA-256 оригиналов и клипов остаются в `shots.csv` для проверки на стороне монтажёра.

## Состав пакета

| Файл | Содержание |
| --- | --- |
| `shots.csv` | Одна строка на план: статус (видео или карточка), таймкоды и секунды песни, число кадров на 30 кадров/с, оригинал с частотой и длительностью, вход рецепта, выбранный участок в секундах на сетке 30 кадров/с и в кадрах исходной частоты, скорость, удержания, стоп-кадр, принятый клип, WAV и рецепт липсинка, промпт, входы, камера, действие, непрерывность, хеши |
| `timeline.edl` | CMX3600 на 30 кадров/с non-drop: события по входам рецептов, `M2` для изменённой скорости, комментарии об удержаниях, стоп-кадрах и исходных частотах; карточки как комментарии |
| `timeline.fcpxml` | Шкала аниматика из принятых клипов и карточек по порядку, песня связанным клипом; импорт в Final Cut Pro, DaVinci Resolve, Premiere Pro |
| `lyrics.csv` | Строки песни с оценками начала и конца из `plan/audio/timing.json` и текстом из `source/text.md` |
| `bundle.json` | Все данные пакета для скриптов |
| `README.md` | Пояснение полей, интервалов и оговорок для монтажёра |

Интервалы читаются так: `source_in_s`/`source_out_s` — секунды выбранного участка входа рецепта на сетке 30 кадров/с после конвертации (как в `build_review` и манифестах), `source_in_frame_native`/`source_out_frame_native` — те же границы в кадрах исходной частоты оригинала (например, 24 кадра/с), начало включительно, конец исключительно. Для планов, собранных из чужой генерации (`source_shot` отличается от `shot`), вход рецепта — промежуточный файл комплекта, например `edit-source.mp4`.

Повтор выбранного участка виден в `repeat_full_cycles`, `repeat_tail_frames`, `repeat_cycle_frames` таблицы и JSON: число полных циклов, длина хвоста и длина цикла в кадрах 30 FPS. EDL содержит отдельное событие каждого цикла и хвоста с непрерывными таймкодами песни; FCPXML использует готовый принятый клип и не повторяет обработку.

## Тесты

Таблица, таймкоды и кадры исходной частоты, EDL с `M2`, структура FCPXML с песней на связанной дорожке, строки песни, отказ при непустой папке, режим копирования с сохранением байтов и относительными путями.

```sh
python3 -B tools/export_edit_bundle/test_export_edit_bundle.py
python3 -B tools/run_tests/run_tests.py --only test_export_edit_bundle
```

Тесты работают на временной фикстуре и не трогают assets. Для полного набора — [run_tests](../run_tests/README.md).
