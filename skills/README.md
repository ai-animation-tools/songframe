# Промпты заданий агента

Источники инструкций для заданий Claude Code или Codex, которые запускает приложение. Клип ведётся кнопками приложения; эти файлы не являются навыками для ручного запуска агента в папке клипа и не устанавливаются в проекты. Задания работают в режиме предложения (`output=proposal`): агент получает инструкции и контекст через stdin, возвращает один JSON и не записывает файлы, не вызывает shell и инструменты. Проверку, показ, применение предложения, согласования, генерацию медиа и платную отправку ведёт приложение.

| Файл | Кто читает | Назначение |
| --- | --- | --- |
| [ai-clip-scenario/SKILL.md](ai-clip-scenario/SKILL.md) | `src/main/scenario-workflow.ts` вкладывает файл целиком в промпт прохода `treatment`, `scenes` или `revise` | Кастинг и трактовка, заполнение реестра сцен, доработка выбранных планов; правила состояния героев |
| [ai-clip-scene/SKILL.md](ai-clip-scene/SKILL.md) | `src/main/production-workflow.ts` склеивает три файла `ai-clip-scene` в промпт этапа `description`, `prompt` или `request` | Контекст задания, непрерывность, длительность и опоры, выбор модели и входов, речевые планы |
| [ai-clip-scene/references/app-proposal.md](ai-clip-scene/references/app-proposal.md) | то же | JSON-контракт ответа каждого этапа |
| [ai-clip-scene/references/prompt-template.md](ai-clip-scene/references/prompt-template.md) | то же | Каркас промптов опор и видеопромпта |

Формат ответа и ограничения, которые проверяет приложение, дополнительно задаёт сам код в конце промпта. Особенности конкретных сервисов генерации в эти файлы не входят: к промпту этапа производства приложение добавляет раздел «Указания агенту» из документа выбранного провайдера `docs/providers/<вид>/<id>.md` (`src/main/provider-guides.ts`). Пути этих файлов вшиты в код (`src/main/scenario-workflow.ts`, `src/main/production-workflow.ts`), а пути всех файлов скиллов — ещё и в проверку упаковки (`scripts/runtime/linux-package.cjs`): при переименовании меняйте их вместе. Папка входит в поставку приложения как `resources/skills` (только `*.md`).

Фронтматтера у файлов нет: это обычный markdown, вкладываемый в промпт. Ссылки между файлами относительные; агенту они не нужны для работы, поскольку все три файла `ai-clip-scene` уже переданы в одном промпте.
