# Проверка Windows-поставки

Windows ZIP собирается на Linux. В Windows VM проверены встроенный Python и библиотеки, FFmpeg/ffprobe и короткий медиапрогон, вход в провайдера генерации (прежним официальным CLI; собственный клиент провайдера в VM не проверялся), загрузка модели и локальное распознавание. Эти проверки не подтверждают полный производственный цикл. CI и Release автоматически собирают Linux AppImage и Windows ZIP на Linux. Проверка ZIP подтверждает целостность архива и состав ресурсов, без исполнения Windows-кода; новые VM-прогоны выполняются по явному поручению.

Распакуйте **весь ZIP** в любую обычную папку. Рядом с `SongFrame.exe` должна остаться папка `resources` и остальные файлы приложения. Для запуска откройте `SongFrame.exe`. Устанавливать Node.js, Yarn, Python или pip не нужно.

Для технической проверки откройте `check-runtime.cmd` двойным щелчком. Он проверяет встроенный Python, библиотеки, вложенный интерпретатор, FFmpeg/ffprobe, короткое кодирование и чтение тестового файла, запуск инструмента и задания приложения во временном проекте в папке с кириллицей и пробелами, клиенты встроенных провайдеров генерации (без сети) и загрузчик модели. Python-процессы получают в PATH только встроенные медиабинарники; пользовательские проекты и платная генерация не используются. Проверка клиента провайдера не отправляет генерацию и не подтверждает вход.

Отчёты `result.json` и `check.log` сохраняются **в этой же папке, рядом с EXE и check-runtime.cmd**. Оба файла создаются до запуска приложения. Начальный `result.json` с `stage: launcher` означает, что приложение ещё не записало результат; успешная проверка заменяет его на `ok: true`, ошибка приложения — на `ok: false` с текстом причины. Если запуск не удался, отправьте оба файла и текст показанной Windows ошибки. Можно перенести всю папку приложения в каталог с кириллицей и пробелами и повторить проверку.

Веса faster-whisper устанавливаются отдельно: кнопкой «Скачать модель …» в окне автоматической разметки. Скачивание и распознавание требуют отдельной модели; обычная runtime-проверка её не загружает. Вход в провайдера генерации выполняется на странице «Среда»; авторизация сохраняется в папке состояния приложения (подпапка `providers\<id>` провайдера).

Клип ведётся кнопками приложения; командная строка для работы с проектом не нужна. Менеджер заданий внешних Claude/Codex сейчас поддерживает только Linux; встроенные провайдеры генерации с прямым вызовом и Python-инструменты не требуют этих агентов. Провайдер изображений, которого исполняет агент, в Windows недоступен.
