# align_lyrics

Строит черновик разметки песни `plan/audio/timing.json`: выравнивает точный текст `source/text.md` по словам локального распознавания и оценивает начало и конец каждой строки. Использовать на этапе разметки трека (скилл `ai-clip-audio`) и при повторной разметке после замены трека или текста. Оценки не подтверждены на слух: подтверждение делает пользователь в редакторе таймингов приложения, подтверждённые строки инструмент сохраняет.

## Контракт

Из корня комплекса, для выбранного проекта:

```sh
python3 -B tools/align_lyrics/align_lyrics.py --dry-run
python3 -B tools/align_lyrics/align_lyrics.py
python3 -B tools/align_lyrics/align_lyrics.py --recognition /tmp/recognition.json
python3 -B tools/align_lyrics/align_lyrics.py --model ~/.local/share/songframe/models/faster-whisper-medium --keep-recognition /tmp/recognition.json
python3 -B tools/align_lyrics/align_lyrics.py --json
```

- Без `--recognition` запускается [transcribe_local](../transcribe_local/README.md) с моделью из `--model` (в приложении — выбранная пользователем или рекомендованная внешняя модель; в CLI — `SONGFRAME_MODEL_DIR` или каталог данных ОС: `$XDG_DATA_HOME/songframe/models/faster-whisper-medium`, при отсутствии XDG_DATA_HOME — `~/.local/share/...`, на Windows — `%LOCALAPPDATA%/songframe/models/faster-whisper-medium`) напрямую через текущий `sys.executable`, с `--allow-network`. Обязательного `unshare` нет: его наличие не гарантирует разрешение user namespaces, из AppImage возможен отказ записи `uid_map`. Модель читается только локально, скачивание отключено. JSON распознавания сохраняется вне проекта (`--keep-recognition` или временная папка). FFmpeg/ffprobe в Linux- и Windows-приложении берутся из поставки через PATH общего launcher. Пользовательский `--model` имеет приоритет над моделью приложения. Распознавание трека длится несколько минут на CPU.
- Модель скачивается отдельно по [инструкции](../../README.md#модель-распознавания). При проверке папки допускаются `vocabulary.txt` и `vocabulary.json`; `--device auto` (по умолчанию) или `--device cpu` передаются распознавателю. CUDA требует отдельно установленных библиотек, иначе используется CPU.
- Формат проверяется до распознавания: пустые/непарные скобки, заголовок вместе со словами, Markdown-списки и названия частей без скобок вызывают ошибку с номером строки. UTF-8 BOM и CRLF допускаются; пустые строки между секциями необязательны.
- Текст: одна строка песни на строку файла, заголовки частей в квадратных скобках, пустые строки разделяют части. `source_line` в разметке это физический номер строки `text.md`, заголовки и пустые строки нумерацию не сдвигают.
- Выравнивание: глобальное сопоставление последовательностей слов (нормализованных, без пунктуации, ё как е) с нечётким сравнением; строка получает начало первого и конец последнего сопоставленного слова. Строки без сопоставленных слов получают оценку интерполяцией между соседями, пересечения соседних строк убираются по середине. В `note` записывается число совпавших слов и пометка «сверка на слух не выполнена».
- `sections`: части по заголовкам текста (начало первой строки, конец последней) плюс «Вступление», «Проигрыш после «…»» для промежутков длиннее 2 с и «Финал без вокала».
- Существующий `timing.json`: строки с `verified: true` переносятся без изменений (по `source_line`), остальные пересчитываются; `--reset` пересчитывает всё. `--output` пишет в другой файл, `--dry-run` только печатает.
- Формат файла использует версию 2 (`version`, `status`, `source`, `sha256`, `duration_decoded`, `duration_container`, `clock`, `lines`, `sections`); добавлено поле `verified` у строк. Разметка не задаёт монтажные окна сцен.

## Тесты

Синтетическое распознавание без модели и сети: ошибки распознавания, лишние слова, нераспознанные строки, части и сохранение подтверждённых строк.

```sh
python3 -B tools/align_lyrics/test_align_lyrics.py
python3 -B tools/run_tests/run_tests.py --only test_align_lyrics
```
