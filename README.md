# SongFrame

Настольное приложение для создания музыкального клипа с помощью ИИ: от трека, текста и идеи до аниматика и пакета для монтажёра. Каждый клип хранится в отдельной папке проекта; приложение помогает подготовить сценарий, создать опорные кадры и видео, проверить стыки и собрать результат.

## Возможности

- **Проекты и исходники.** Создание клипа и история проектов. Загрузка трека, текста песни, идеи, обложки и референсов: персонажей, транспорта, локаций и собственных типов. Файлы можно выбирать через диалог или перетаскивать в окно.
- **Разметка трека.** Локальное распознавание песни, волна аудио, ручное изменение границ строк, прослушивание и подтверждение на слух. Правки сохраняются по кнопке «Сохранить».
- **Кастинг и сценарий.** Описание героев и мира, трактовка по частям песни, планы с камерой и действием. Наследование состояния помогает следить за непрерывностью между сценами. Предложения агента можно просмотреть и доработать до применения; готовые ручные данные тоже поддерживаются.
- **Производство.** Подготовка описания сцены, опор, видеопромпта и запроса. Изображения создаются через Codex или Kling либо импортируются из PNG, JPG и WebP; видео — через Kling. Результаты просматриваются и принимаются отдельно.
- **Просмотр сцен.** Карточки, поиск, фильтры и статусы. Можно сравнить оригинал генерации с принятым монтажом, посмотреть опоры и перейти к нужной сцене в производстве или аниматике.
- **Проверки и пробы.** Проверка согласованности материалов и сборка коротких роликов для оценки отдельных сцен и стыков.
- **Ручной монтаж пробы.** Отмеченные сцены на видеодорожке под выбранный участок песни: обрезка, перенос склейки, выбор участка исходника, просмотр со звуком, сохранение монтажа и экспорт MP4. Готовый монтаж можно явно применить к принятым сценам с сохранением прежних файлов. [Порядок работы](docs/montage.md).
- **Аниматик и экспорт.** Сборка полного клипа с принятыми сценами и карточками незавершённых планов, просмотр по главам и приёмка результата. Экспорт пакета с медиа для монтажёра.
- **Среда и настройки.** Проверка готовности встроенных инструментов и входа Kling, выбор текстового агента, модели и пути к CLI. Светлая и тёмная темы.
- **Справка.** Первые шаги, ответы на практические вопросы и объяснения терминов с примерами. Поиск работает по названиям, тексту и синонимам; страница доступна из бокового меню даже без открытого проекта.

Платная отправка в Kling требует отдельного подтверждения: приложение показывает промпт, входные материалы, стоимость и остаток. Скачанный результат ещё не считается принятым. Прерванная отправка не повторяется автоматически.

## Установка и первый запуск

Скачайте подходящую сборку со страницы [релизов](https://github.com/ai-animation-tools/songframe/releases):

| ОС | Поставка | Запуск |
| --- | --- | --- |
| Linux x64 | AppImage | Разрешите выполнение файла и откройте его |
| Windows x64 | ZIP | Распакуйте архив целиком и запустите `SongFrame.exe` |

В обе поставки входят Python, FFmpeg/ffprobe и Kling CLI. Отдельно устанавливать Python, Node.js, Yarn, pip или FFmpeg для работы готового приложения не нужно. **Модель распознавания скачивается отдельно** через окно автоматической разметки. GPU не обязателен.

1. Создайте проект или откройте существующую папку клипа.
2. На странице **«Исходники»** добавьте трек, текст песни, идею и референсы.
3. На странице **«Среда»** проверьте готовность инструментов и войдите в Kling, если будете использовать генерацию.
4. В Linux настройте Claude Code или Codex на странице **«Настройки»**, если хотите получать предложения агента.
5. Разметьте песню на странице **«Тайминги»**, затем переходите к кастингу, сценарию и производству.

Запуск Claude Code и Codex из приложения сейчас поддерживается только на Linux. Локальные инструменты, разметка и встроенный Kling доступны в обеих ОС. Git необязателен для локальной работы, но нужен для истории изменений проекта.

## Агенты и генерация

Claude Code или Codex устанавливается и авторизуется отдельно: [инструкция Claude Code](https://code.claude.com/docs/en/setup), [инструкция Codex CLI](https://learn.chatgpt.com/docs/codex/cli). Вход выполняется в терминале через `claude auth login` или `codex login`. Просмотр проектов, редактирование и локальные инструменты доступны без агента.

На странице **«Настройки»** выберите провайдера. Поле **«Модель»** можно оставить пустым — используется модель самого CLI. При необходимости укажите путь к его исполняемому файлу. Кнопка проверки подскажет, если CLI не найден или требуется вход. Ниже показываются доступные сведения аккаунта и лимиты; неизвестные значения обозначаются как «Не удалось уточнить». Кнопка **«Обновить»** перечитывает их, а **«Сохранить»** записывает выбор агента. Наличие входа и название тарифа не подтверждают оплату подписки.

Сначала явно выберите и сохраните агента на странице **«Настройки»**. Пока выбрано «Без агента» или доступность CLI и вход не подтверждены, действия ИИ заблокированы с пояснением. На странице **«Проект»** отдельно выберите и сохраните провайдеры: видео использует Kling, изображения — Codex или Kling. Старые значения по умолчанию не считаются выбором: список показывает «Не выбрано», пока пользователь не подтвердит провайдера. Codex для изображений доступен только при выбранном агенте Codex; при Claude и «Без агента» приложение не проверяет Codex для изображений. Для Kling доступны модели и параметры выбранного аккаунта; несовместимую замену приложение объясняет при согласовании. Настройки не меняют уже подготовленные запросы.

Настройки и производство читают единый каталог возможностей Kling. Одновременные проверки используют один выполняющийся запрос; после его завершения следующее обновление получает свежие данные аккаунта. Ошибки отдельных команд сохраняются, а не подменяются сохранённым каталогом или статическим списком моделей.

Для изображений Codex модель агента выбирается здесь же, из каталога CLI; пункт **«Как указано в Codex CLI»** сохраняет его собственный выбор. Сейчас создаётся один вариант каждой опоры, а точный размер изображения через промпт не гарантируется. Параметры количества, разрешения и пропорций Kling к этому способу генерации не применяются.

Предложения сценария и производства показываются до записи изменений. Приёмка сцены, принятие аниматика и платная отправка — отдельные действия. Подробнее: [сценарный процесс](docs/scenario-workflow.md) и [производственный процесс](docs/production-workflow.md).

Обложка служит только оформлением проекта. Её смена и удаление не снимают утверждения кастинга и сценария и не делают готовые предложения устаревшими. Для актуальности учитываются содержательные поля исходников, включая трек, текст, идею и референсы; время сохранения манифеста не является входом производства.

Смена провайдера, модели и других настроек генерации не требует обновлять карточки, списки или уже собранный аниматик. Для карточек учитывается название проекта, для сборки — название и имя выходного MP4; сцены, трек и выбранные медиа проверяются отдельно.

На странице «Исходники» в блоке обложки нажмите «Сгенерировать». Заполненная «Идея клипа» становится основой редактируемого промпта; если идеи нет, введите описание вручную. Используется провайдер изображений из настроек проекта: Codex с моделью из настроек проекта либо Kling с выбранной или автоматически подобранной совместимой моделью. Для изображений Codex должен быть явно выбран агент Codex; при Claude используется только явно выбранный совместимый провайдер, например Kling. Перед каждой генерацией открывается подтверждение с полным промптом. Для Kling также показываются модель, SHA запроса, стоимость и остаток. Если стоимость неизвестна, кнопка «Я согласен» разрешает одну попытку с неизвестным списанием; затем нужно подтвердить промпт и генерацию. Обновление стоимости и кнопка «Ещё» требуют нового согласия. Известная нехватка средств и неизвестный остаток при известной цене блокируют отправку. «Ещё» подготавливает одну новую попытку с тем же промптом и снова открывает подтверждение; автоматических повторов при ошибке нет.

В окне результата переместите квадратное выделение и измените его размер. «Принять» подставляет выбранную область в форму, а «Сохранить» записывает её как обложку проекта. Кандидаты и журналы этой сессии находятся в системной временной папке, вне проекта и каталога данных SongFrame. «Закрыть» останавливает локальное ожидание и удаляет временную сессию; отправленный в Kling запрос при этом может уже быть оплачен. После принятия остаётся только обрезанный PNG до сохранения формы, замены обложки или ухода со страницы. Аварийное завершение может оставить файлы только в системной временной папке.

На странице «Монтаж пробы» плеер расположен слева, сведения о выбранной сцене — справа. Кнопка «Материалы сцен» в правом блоке открывает каталог поверх страницы; выбор материала не закрывает его. Панель закрывается кликом снаружи, кнопкой «Закрыть» или Escape.

Каталог занимает не меньше половины широкого окна и подбирает число колонок по доступной ширине; на узком экране раскрывается на всю ширину. Открытие новой пробы и чтение длительности видео не считаются несохранённой правкой. Изменения монтажа, музыки и названия отслеживаются относительно открытого или сохранённого состояния.

Подробные результаты и события инструментов и агентов собраны на отдельной странице «Журнал заданий». На рабочих страницах остаются текущий статус и необходимые действия; журнал открывается из общего меню. Карточки заданий общие, без отдельных копий для страниц.

В списках собранных пакетов для монтажёра и проб есть удаление с подтверждением. Для пакета удаляется его папка экспорта с копиями медиа; для пробы — выбранный MP4 и рецепт. Исходные материалы и принятые сцены сохраняются. Готовые экспорты и пробы распознаются проверкой порядка в проекте и не считаются бесхозными рабочими пакетами.

## Сравнение материалов сцены

В подробностях на странице «Сцены» оригинал генерации и принятый монтаж показаны рядом, с описаниями под плеерами. Кнопка «Воспроизвести синхронно» сопоставляет монтаж с нужным участком оригинала, учитывая обрезку, скорость, удержания и стоп-кадр. Звук оригинала на время сравнения выключается, пауза монтажа останавливает оба видео.

Подписи входных изображений показываются полностью. Клик по входу открывает галерею: изображение можно вписать в окно или посмотреть в оригинальном размере 1:1 с прокруткой. Стрелки переключают входы, Escape закрывает окно.

## Изображения референсов

На странице «Исходники» каждая сущность сворачивается в отдельную секцию с названием и количеством изображений. Внутри каждое изображение занимает строку: картинка и вид, многострочное описание, собственный промпт. Промпты разных видов сохраняются независимо.

Для добавления изображений перетащите их в область загрузки под строками или нажмите на неё. Область также доступна с клавиатуры через Enter и пробел. Изменения записываются в проект только кнопкой «Сохранить».

## Формат текста песни

Для трека, обложки, текста песни и идеи используйте область загрузки: перетащите в неё файл или нажмите на неё, чтобы выбрать файл. Область доступна с клавиатуры через Enter и пробел. Содержимое TXT или MD в UTF-8 подставляется в поле для дальнейшей правки. В проект изменения записываются после нажатия «Сохранить»; для текста песни сохраняется та же проверка формата при обоих способах импорта.

В поле «Текст песни» и в импортируемом TXT/MD используется обычный текст в UTF-8. Каждая исполняемая строка записывается отдельно, название секции — отдельной строкой в квадратных скобках. Секции необязательны, их названия произвольные; пустые строки разрешены и не обязательны. Повторяющиеся припевы записываются полностью в порядке исполнения.

```text
[Куплет 1]
Первая строка песни
Вторая строка песни

[Припев]
Строка припева
Ещё одна строка
```

Заголовки `[Припев]` не являются строками для таймингов. Нумерация, Markdown-заголовки/списки, непарные или пустые скобки не допускаются: поле показывает ошибку с номером строки, сохранение недоступно до исправления. При импорте некорректный текст остаётся в поле для правки. Если текст изменён после разметки и старый тайминг попал на заголовок или удалённую строку, такая привязка не показывается; приложение объясняет необходимость повторной разметки, не изменяя старый файл автоматически.

## Музыкальные секции на шкале

Страница «Тайминги» показывает сохранённые `sections` из `plan/audio/timing.json`. Обычное сохранение и изменение вокальных строк сохраняют границы, названия и заметки этих секций: короткие переходы, инструментальные участки и затухания не заменяются автоматически. Точные длительности из разметки также сохраняются. Если секций ещё нет, шкала и сохранение строят их по заголовкам текста и временам строк.

Кнопка **«Пересчитать секции»** заново строит части по текущим строкам, заменяя прежние границы, названия и заметки. Результат сначала виден на шкале как несохранённая правка; его можно сохранить или отменить вместе с остальными правками. Повторное распознавание песни для этого не требуется. Автоматическая разметка остаётся отдельной операцией, которая создаёт новую карту секций.

## Модель распознавания

Откройте **«Тайминги → Разметить автоматически»**. Приложение показывает CPU, RAM, обнаруженную NVIDIA и доступность CUDA, рекомендует модель и предлагает скачать её кнопкой в этом же окне. Можно выбрать другую модель или любую уже скачанную папку. При слабой, AMD или Intel видеокарте используется CPU; наличие хорошей NVIDIA само по себе ещё не означает, что установлены библиотеки CUDA.

| Модель | Загрузка весов | Когда попробовать |
| --- | --- | --- |
| [small](https://huggingface.co/Systran/faster-whisper-small) | около 0,5 ГБ | Мало памяти, нужен быстрый черновик |
| [medium](https://huggingface.co/Systran/faster-whisper-medium) | около 1,5 ГБ | Обычная работа на CPU, компромисс скорости и точности |
| [large-v3-turbo](https://huggingface.co/dropbox-dash/faster-whisper-large-v3-turbo) | около 1,6 ГБ | Быстрая обработка на подходящей NVIDIA |
| [large-v3](https://huggingface.co/Systran/faster-whisper-large-v3) | около 3,1 ГБ | Приоритет точности, достаточно памяти; на CPU значительно медленнее |

При доступной CUDA приложение предлагает small от 2 ГБ видеопамяти, turbo от 4 ГБ и large-v3 от 8 ГБ. Для CPU ориентир — medium при RAM от 8 ГБ и от 4 логических потоков, иначе small. Это приблизительные рекомендации, а не измерение скорости и гарантия достаточной свободной памяти; на GPU может одновременно работать другая программа. Более крупная модель тоже может ошибаться на пении и музыке, границы строк нужно подтверждать на слух.

### Загрузка из приложения

Откройте «Тайминги → Разметить автоматически», выберите модель и нажмите **«Скачать модель small/medium/…»**. Размер и папка показаны рядом с кнопкой. Приложение запускает встроенный загрузчик фоновым заданием; индикатор и журнал видны в том же окне. Диалог можно закрыть и открыть снова — загрузка продолжится. После успеха папка выбирается автоматически, сведения о файлах обновляются; перезапуск и отдельная проверка не нужны. При ошибке повторное нажатие продолжает загрузку с сохранением скачанных данных.

Команды загрузки для терминала приведены в [дополнительной инструкции](docs/development.md#модель-распознавания-из-терминала).

### Выбор скачанной папки и работа без сети

После загрузки кнопкой папка выбирается автоматически. Для ранее скачанных моделей используйте **«Использовать папку»** либо **«Обзор»**. **«Обновить сведения»** повторно проверяет CPU, CUDA и наличие файлов в стандартных папках — например, после ручного копирования модели или установки библиотек GPU. Перезапускать приложение не нужно. Поле пути запоминается. Пустое поле использует стандартную папку рекомендованной модели. Можно держать несколько моделей и переключать папку; обновление приложения их не затрагивает. После переустановки ОС или переноса папки достаточно выбрать путь заново.

Для ручного скачивания откройте ссылку **«Файлы модели»** в приложении и сохраните файлы из вкладки Files and versions в одну папку. Нужна версия **faster-whisper / CTranslate2**, а не исходные веса `openai/whisper-*`: минимум `model.bin`, `config.json`, `tokenizer.json` и `vocabulary.txt` **или** `vocabulary.json`. Если в репозитории есть `preprocessor_config.json`, скачайте и его. Уже скачанную модель можно использовать повторно: выберите её папку, скачивать заново не нужно.

Распознавание работает локально и использует только файлы выбранной модели. После её загрузки подключение к сети для анализа трека не требуется; аудио внешним сервисам не передаётся.

### Необязательное ускорение NVIDIA

Для CPU ничего дополнительно устанавливать не нужно. Для CUDA требуются совместимая NVIDIA, её драйвер, **cuBLAS для CUDA 12 и cuDNN 9** — это [требования faster-whisper](https://github.com/SYSTRAN/faster-whisper#gpu). Эти крупные библиотеки не включены в AppImage. Установка: [CUDA под Linux](https://docs.nvidia.com/cuda/cuda-installation-guide-linux/), [CUDA под Windows](https://docs.nvidia.com/cuda/cuda-installation-guide-microsoft-windows/), [cuDNN](https://docs.nvidia.com/deeplearning/cudnn/installation/latest/). Выберите версии CUDA 12.x и cuDNN 9 для CUDA 12, даже если сайт предлагает более новую ветку.

После установки библиотеки должны быть доступны загрузчику: на Linux — системная конфигурация библиотек или `LD_LIBRARY_PATH`, на Windows — каталог DLL в `PATH`. Перезапустите приложение, откройте разметку и нажмите **«Повторить проверку»**. Окно покажет, чего не хватает. Если проверка CUDA не проходит, обработка использует CPU. При нехватке видеопамяти можно выбрать меньшую модель или режим **«Только CPU»**; файлы модели остаются теми же. В JSON распознавания записывается фактический режим обработки.

## Проекты и перенос

Каждый клип — отдельная папка с исходниками, сценарием и материалами. Чтобы переименовать клип, откройте **«Проект → Переименовать»**: название в шапке и истории обновится, папка и имя итогового MP4 сохранятся.

Настройки, история и журналы приложения хранятся отдельно от его файла и сохраняются после обновления. Фактическая папка состояния видна на странице **«Среда»**. Модели распознавания тоже хранятся отдельно и используются повторно после обновления.

После переноса приложения или папки клипа откройте проект заново: служебные команды обновятся для нового расположения. Если прежний путь остался в истории, его можно забыть в списке проектов и выбрать перенесённую папку. Пользовательские правила, исходники и принятые материалы при обновлении служебных файлов сохраняются.

## Уведомления

После разметки трека, сборки пробы, аниматика и пользовательских заданий Claude Code/Codex приложение сообщает об успехе или ошибке системным уведомлением. Явная отмена уведомления не вызывает. Подготовленный рецепт пробы и проверка входов аниматика обозначаются отдельно от готового видео.

Нажатие на уведомление возвращает окно к проекту и странице результата. Уведомления работают и при свёрнутом окне, пока приложение запущено; после выхода фоновой работы нет. Их показ может быть отключён настройками ОС.
