# download_whisper_model

Скачивает модель faster-whisper из Hugging Face в указанную папку. Использует встроенные Python и `huggingface_hub` через общий launcher приложения; отдельные Python, pip и `hf` устанавливать не нужно. Для загрузки нужна сеть, аудио и другие данные проекта инструмент не читает.

Из папки открытого в приложении проекта на Linux:

```sh
./.songframe/run-tool download_whisper_model --repository Systran/faster-whisper-medium --output "/absolute/path/to/faster-whisper-medium"
```

На Windows в PowerShell:

```powershell
.\.songframe\run-tool.cmd download_whisper_model --repository Systran/faster-whisper-medium --output "C:\Models\faster-whisper-medium"
```

`--repository` — идентификатор репозитория с моделью CTranslate2; `--output` — обязательный абсолютный путь. Папка создаётся загрузчиком Hub. Необязательный `--project` принимается для совместимости с проектным launcher; выбирать проект отдельно не требуется, его содержимое не меняется. После переноса приложения откройте проект заново для обновления launcher.

Прогресс Hugging Face выводится в терминал. Повтор той же команды использует уже загруженные данные и служебные сведения Hub в папке модели; после прерывания оставьте их на месте и запустите команду ещё раз. Инструмент снимает унаследованный `HF_HUB_OFFLINE` перед импортом Hub только в своём процессе. Офлайн-настройки распознавания не меняются.

Успешный код 0 и сообщение «Модель готова» появляются после окончания загрузки и проверки непустых `config.json`, `model.bin`, `tokenizer.json` и одного из `vocabulary.json` / `vocabulary.txt` — тот же состав проверяет приложение в `src/main/media-runtime.ts`. Это проверка наличия, без повторного хеширования больших весов. При неполном комплекте или ошибке код 1, при неправильных аргументах 2, при прерывании 130; Python traceback не выводится. После загрузки выберите полученную папку в окне разметки.

Тесты без модели и сети, включая повтор команды, прерывание, неполный комплект, унаследованный офлайн-флаг и запуск CLI с пустым `PATH`:

```sh
python3 -B tools/run_tests/run_tests.py --only test_download_whisper_model
```

Тестовый CLI запускается тем же `sys.executable`, что и тесты; если тесты запущены встроенным Python, системный Python не нужен. Hugging Face в тестах заменён локальным модулем.


В приложении тот же инструмент запускается кнопкой «Скачать модель …» в окне автоматической разметки через общий Jobs/PythonLauncher. Прогресс и журнал видны в интерфейсе, скачанная папка выбирается автоматически. Команды выше остаются вариантом ручного запуска.
