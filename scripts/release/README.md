# Инструмент выпуска SongFrame

`release.mjs` управляет подготовкой и публикацией локально собранного выпуска. Его запускает `yarn release` из корня репозитория. Команды `plan`, `prepare` и `publish`, требования к версии и состав комплекта описаны в [руководстве разработчика](../../docs/development.md#выпуск-релиза); это источник порядка выпуска.

`release.test.mjs` проверяет Git-состояние, восстановление загрузки, сохранность файлов и сверку вложений через подменённый GitHub. Тесты используют временные репозитории и маленькие тестовые поставки, без сети, сборки настоящих пакетов и публикации:

```sh
yarn test:release
```

Изменения только этой папки и сопровождающей документации выбирают [адресные группы CI](../ci/README.md): lint, форматирование и тесты инструмента выпуска. Проверки приложения, Python-инструментов и браузерных историй для такого изменения не запускаются.

Job тестов сценария использует Node и Git, без установки Yarn-зависимостей. Для отдельно выбранных ESLint/Prettier команда `yarn install --immutable --mode=skip-build` устанавливает JavaScript-пакеты без postinstall Electron. Сборка поставок использует обычную установку зависимостей.

Для подтверждения исходников инструмент принимает автоматический CI и полный ручной запуск с marker `CI · manual/all`. Частичные `manual/auto` и `manual/selected` не заменяют его: запускайте `gh workflow run CI --ref main -f "mode=Полный набор"`, когда перед выпуском требуется ручная полная проверка.
