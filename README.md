# SongFrame

SongFrame — настольное приложение для производства музыкальных клипов с помощью ИИ: исходники и разметка песни, сценарий и планы, генерация опор и видео у провайдеров медиа с согласованием платных отправок, приёмка, аниматик, монтаж и экспорт для монтажёра. Текстовые этапы выполняет внешний агент, которого запускает само приложение; клип ведётся кнопками приложения. Данные каждого клипа живут в отдельной папке проекта, созданной из встроенного шаблона.

Приложение написано на Go + Wails 3 с React/MUI-интерфейсом.

## Статус

- **Возможности.** Создание и открытие проектов, исходники, разметка песни, сценарий, производство с платной отправкой, проверки, аниматик, монтаж, производные планы и экспорт для монтажёра. Обновление из приложения берёт [выпуски](https://github.com/ai-animation-tools/songframe/releases) этого репозитория.
- **Поставки.** Linux x86_64 — AppImage и deb (Ubuntu 24.04 и новее, glibc 2.39), Windows 10/11 amd64 — установщик NSIS в профиль пользователя. Все проверены вручную на целевых системах. macOS не поддерживается.
- **Профиль.** У приложения app ID `tools.songframe.desktop` и каталог состояния `songframe-desktop` ([подробнее](docs/development.md#каталог-состояния)).
- **Компоненты отдельно.** FFmpeg/ffprobe, ONNX Runtime и модели в поставку не входят: приложение находит их в системе или ставит кнопкой на странице «Компоненты». Без них проект открывается и редактируется.
- **Сборка.** Все поставки собираются локально на Linux (`wails3 task package:linux`, `package:deb`, `package:windows`) и публикуются в [выпусках](https://github.com/ai-animation-tools/songframe/releases).

## Быстрый старт

Нужны Go 1.26+, C-компилятор, Wails CLI 3.0.0, Node.js и Yarn 4.18.1; на Linux — development-пакеты GTK4 и WebKitGTK 6.0. Подробности — в [руководстве разработчика](docs/development.md#окружение-разработчика).

```sh
go install github.com/wailsapp/wails/v3/cmd/wails3@v3.0.0
wails3 task deps                                      # frontend по lock
(cd frontend && yarn playwright install chromium)     # браузер для проверки витрины
wails3 task build                                     # build/bin/songframe
wails3 task run
```

Проверки: во время работы — адресные тесты изменённой области, перед коммитом — один полный прогон (он сам идёт с пониженным приоритетом):

```sh
wails3 task check:all
```

Список задач `Taskfile.yml` и порядок проверок — в [руководстве разработчика](docs/development.md#команды). Настоящие клипы, FFmpeg, модели и соседние репозитории для проверок не нужны.

## Карта репозитория

| Путь | Что там |
| --- | --- |
| `main.go` | Точка входа: каталог состояния, восстановление прерванных операций, сервисы, окно, флаги проверок поставки |
| `component_smoke.go`, `update_smoke.go` | Проверки поставки без окна: установка компонентов с CPU inference и обновление из подставного выпуска |
| `go.mod`, `Taskfile.yml` | Go-модуль и задачи `wails3 task`: сборка, поставки, проверки |
| `internal/app/` | Wails-сервисы — граница между интерфейсом и логикой |
| `internal/<область>/` | Логика областей: проекты, разметка, сценарий, производство, монтаж, агенты, провайдеры, компоненты, обновление |
| `frontend/src/shared/` | Контракт `window.api`, типы, реестры агентов и провайдеров, словари текстов |
| `frontend/src/platform/` | Реализация `window.api` поверх generated bindings |
| `frontend/src/renderer/` | Страницы, общие компоненты, тема, модели для Storybook |
| `frontend/bindings/` | Сгенерированные bindings Wails (вручную не править) |
| `frontend/.storybook/`, `frontend/tests/` | Настройка Storybook и браузерный обход витрины |
| `resources/` | Встраиваемые шаблон проекта, промпты агента, документы провайдеров, шрифты |
| `testdata/` | Эталоны поведения, контракты Go/TS, проект-образец |
| `docs/` | Руководства разработчика, процессы областей, правила UI и генерируемая карта кода |
| `packaging/` | Рецепты поставок: AppImage, deb, установщик NSIS, `VERSION` |
| `scripts/` | Скрипты сборки, поставок и проверок; `scripts/packtool` — инструмент комплекта, `scripts/appimage-bootstrap` — подготовка AppArmor для AppImage |
| `www/` | Лэндинг на GitHub Pages |
| `.github/` | CI исходников и документации, публикация лэндинга, шаблоны issues и PR |
| `dev-skills/` | Скиллы разработки для агентов; `.agents/skills/` и `.claude/skills/` — ссылки на них |
| `AGENTS.md`, `CLAUDE.md` | Правила работы в репозитории для агентов |

## Лицензии

Код распространяется по лицензии MIT ([LICENSE](LICENSE)). Bootstrap AppArmor для AppImage основан на коде [Forktopus](https://github.com/forktopus/forktopus) (MIT, атрибуция — в исходниках `scripts/appimage-bootstrap`). Лицензионные материалы поставки собирает подкоманда `notices` инструмента `scripts/packtool`.

Модели, настоящие проекты, медиа, локальные отчёты, зависимости и результаты сборки в Git не входят.

## История

Начиная с версии 1.0.0 разработка ведётся на стеке Go + Wails. Предыдущий стек Electron (выпуски 0.x) не поддерживается начиная с коммита `d1640b2615d3fe2fc6607e7b1f51d07659c84f0a`; его профиль и настройки приложение не читает.
