# cut_speech

Готовит точный WAV липсинка из исходной песни и рецепт среза `audio-recipe.json` по [контракту assets](../../templates/project/assets/README.md#как-устроено-хранение): декодирование всего трека в PCM 16 бит / 44,1 кГц / стерео и срез по номерам сэмплов без фильтров, нормализации и изменения скорости. Использовать для речевых планов по [справочнику скилла](../../skills/ai-clip-scene/references/lipsync.md) вместо ручного расчёта сэмплов. Исходная песня только читается.

```sh
python3 -B tools/cut_speech/cut_speech.py cut M44 --out plan/batches/M44-attempt-02/audio
python3 -B tools/cut_speech/cut_speech.py cut M44 --out plan/batches/M44-attempt-02/audio --lead 0.7 --tail 0.4 --min-seconds 8
python3 -B tools/cut_speech/cut_speech.py cut M58 --out /tmp/M58-audio --start 244.5 --end 249.0
python3 -B tools/cut_speech/cut_speech.py verify assets/shots/M23/audio-recipe.json
```

Без `--start`/`--end` границы предлагаются по строкам `plan/audio/timing.json`, пересекающим окно плана: от начала первой строки минус `--lead` до конца последней плюс `--tail`, не короче `--min-seconds` (например, длительности запроса). Инструмент печатает найденные строки с текстом из `source/text.md` и их пометками: оценки разметки не подтверждены на слух, поэтому границы нужно прослушать до генерации. Явные `--start`/`--end` задают срез напрямую; начало включительно, конец исключительно, перевод в сэмплы с округлением к ближайшему. Существующий WAV не перезаписывается.

Рецепт содержит источник с SHA-256, интервал в секундах и сэмплах, параметры PCM, SHA-256 результата, а также строки разметки, по которым выбран срез. `verify` повторяет срез по рецепту и сверяет SHA-256 файла; при расхождении контейнера дополнительно сравнивает содержимое PCM — так WAV с другим служебным заголовком можно проверить по содержимому PCM.

## Тесты

Выбор строк в окне и предложение границ с запасами, точность среза в сэмплах, формат WAV, проверка рецепта, отказ при существующем файле и выходе за конец песни.

```sh
python3 -B tools/cut_speech/test_cut_speech.py
python3 -B tools/run_tests/run_tests.py --only test_cut_speech
```

Тесты создают короткий WAV во временной папке. Для полного набора — [run_tests](../run_tests/README.md).
