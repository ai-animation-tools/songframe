# Контракты проектов SongFrame

Работай в корне репозитория SongFrame (в рабочем пространстве AI Animation Tools это папка `songframe/`); пути ниже отсчитываются от него. Перед изменением прочитай актуальные `AGENTS.md` и относящиеся к задаче части `templates/project/AGENTS.md`. Определи владельца изменяемых данных, кто их записывает и читает, какие представления производные и какие существующие данные должны оставаться пригодными для чтения.

При изменении формата хранения согласуй затронутые схемы и шаблон в `templates/project`, Python-инструменты и их документацию, а также чтение, запись и проверки в приложении. Найди потребителей по фактическому полю или пути; не создавай второй источник тех же сведений. Проверяй пользовательские данные на границе чтения и записи и сообщай об ошибках так, чтобы можно было исправить данные. Существующие клип-проекты не изменяй без отдельного поручения.

Для обновления интеграции проекта проверь `docs/development.md` и соответствующую реализацию в `src/main`: управляемые памятки, настройки схем, launcher и `.songframe` должны сохранять пользовательский текст и настройки. Учитывай относительные пути, перенос проекта и приложения, команды Linux и Windows; проверку Windows не выводи из одной проверки на Linux.

Если меняется установка навыков в проект, прочитай `skills/README.md`, `src/main/managed-skills.ts` и его тесты. Учитывай копии для Codex и Claude Code, манифест и сохранение пользовательских изменений; наличие файлов само по себе не подтверждает обнаружение навыка агентом.

Выбирай проверки по изменённым потребителям: соседние Python-тесты и `tools/run_tests/README.md`, тесты главного процесса через `yarn test`, при изменении TypeScript — `yarn typecheck`. Для интеграции проекта проверяй создание и повторное открытие на временных фикстурах, сохранение пользовательских данных и переносимые пути. Результаты проверок и ограничения платформы сообщай отдельно; нативная Windows VM запускается только по явному поручению.
