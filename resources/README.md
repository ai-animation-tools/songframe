# Ресурсы оболочки

`icon.png` и `icon.ico` перенесены из SongFrame, срез `634fd9429ba0b0cfcb984a52ce95adf8e1674635`. Исходное изображение предоставлено пользователем; это его производные для приложения. Корневая лицензия MIT сохранена в `LICENSE`.

Сейчас собирается нативный исполняемый файл без установщика; подключение платформенных иконок при упаковке относится к следующему этапу. Исходный JPEG, модели, медиа клипов и экспериментальные отчёты в поставку не копируются.
