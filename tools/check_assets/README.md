# check_assets

Проверяет все выбранные комплекты: наличие локальных файлов и общих референсов из `source`, SHA-256, рецепт обработки и соответствие длины каноническому окну сцены. Использовать перед полной сборкой или при порученном аудите.

```sh
python3 -B tools/check_assets/check_assets.py
```

Аргументов нет; читает `assets/shots/Mxx/manifest.json` и `plan/scenes.json`, ничего не записывает. Для обычной приёмки одной сцены достаточно [asset_package](../asset_package/README.md): он сверяет её FPS и монтажное окно с реестром, без повторной проверки всего проекта. Успех технической проверки не является новой художественной приёмкой.

## Тесты

Сводка из локальных манифестов временного проекта, отказ для комплекта вне реестра и при длине, не совпадающей с окном.

```sh
python3 -B tools/check_assets/test_check_assets.py
python3 -B tools/run_tests/run_tests.py --only test_check_assets
```
