# SongFrame

SongFrame — настольное приложение для производства музыкальных клипов с помощью ИИ: исходники и разметка песни, сценарий и планы, генерация опор и видео у провайдеров медиа с согласованием платных отправок, приёмка, аниматик, монтаж и экспорт для монтажёра. Текстовые этапы выполняет внешний агент, которого запускает само приложение; клип ведётся кнопками приложения. Данные каждого клипа живут в отдельной папке проекта, созданной из встроенного шаблона.

Это Go-версия на Go + Wails 3 с React/MUI-интерфейсом, преемник Electron-SongFrame. После переключения её история станет публичным репозиторием `ai-animation-tools/songframe` версии 1.0.0.

## Статус

- **Функции перенесены.** Создание и открытие проектов, исходники, разметка песни, сценарий, производство с платной отправкой, проверки, аниматик, монтаж, производные планы и экспорт работают через Go. Недоступны только обновление из приложения (`updates.*`) и `app.setToolsRoot`: инструменты встроены в приложение.
- **Поставки ранние.** Есть Linux x86_64 AppImage (база Ubuntu 24.04, glibc 2.39) и Windows amd64 NSIS; deb-пакета пока нет. Windows-установщик собран и проверен по составу, но нативно в Windows не проверялся. macOS не проверялся.
- **Профиль отдельный.** До переключения у приложения свой app ID `tools.songframe.go.dev` и каталог состояния `songframe-go-dev`; профиль, токены и клипы Electron-версии автоматически не читаются.
- **Компоненты отдельно.** FFmpeg/ffprobe, ONNX Runtime и модели в поставку не входят: приложение находит их в системе или ставит кнопкой на странице «Компоненты». Без них проект открывается и редактируется. Python не нужен.
- **Публикация не настроена.** Выпуск релизов и обновление из приложения ещё не реализованы.

## Быстрый старт

Нужны Go 1.26+, C-компилятор, Wails CLI 3.0.0, Node.js и Yarn 4.18.1; на Linux — development-пакеты GTK4 и WebKitGTK 6.0. Подробности — в [руководстве разработчика](docs/development.md#окружение-разработчика).

```sh
go install github.com/wailsapp/wails/v3/cmd/wails3@v3.0.0
wails3 task deps                                      # frontend по lock
(cd frontend && yarn playwright install chromium)     # браузер для проверки витрины
wails3 task build                                     # build/bin/songframe-go
wails3 task run
```

Проверки: во время работы — адресные тесты изменённой области, перед коммитом — один полный прогон, лучше с пониженным приоритетом:

```sh
nice -n 19 ionice -c3 wails3 task check:all
```

Список задач `Taskfile.yml` и порядок проверок — в [руководстве разработчика](docs/development.md#команды). Настоящие клипы, Python, FFmpeg, модели и соседние репозитории для проверок не нужны.

## Карта репозитория

| Путь | Что там |
| --- | --- |
| `main.go` | Точка входа: каталог состояния, восстановление прерванных операций, сервисы, окно |
| `internal/app/` | Wails-сервисы — граница между интерфейсом и логикой |
| `internal/<область>/` | Логика областей: проекты, разметка, сценарий, производство, монтаж, агенты, провайдеры, компоненты |
| `frontend/src/shared/` | Контракт `window.api`, типы, реестры агентов и провайдеров, словари текстов |
| `frontend/src/platform/` | Реализация `window.api` поверх generated bindings |
| `frontend/src/renderer/` | Страницы, общие компоненты, тема, модели для Storybook |
| `frontend/bindings/` | Сгенерированные bindings Wails (вручную не править) |
| `resources/` | Встраиваемые шаблон проекта, промпты агента, документы провайдеров, шрифты |
| `testdata/` | Эталоны Electron-версии, контракты Go/TS, проект-образец |
| `packaging/`, `scripts/` | Рецепты и скрипты поставок |
| `dev-skills/` | Скиллы разработки для агентов |

## Происхождение и лицензии

Интерфейс, шаблон проекта, промпты, документы провайдеров, шрифты и иконки перенесены из Electron-SongFrame на срезе `634fd9429ba0b0cfcb984a52ce95adf8e1674635`; поведение этого среза зафиксировано эталонами `testdata/golden`. Исходное уведомление MIT сохранено в [LICENSE](LICENSE). Electron-зависимости удалены, добавлен `@wailsio/runtime` 3.0.0. Устройство Wails-сервисов и Taskfile сверено с проектом Forktopus; применяется [механизм services и generated bindings Wails](https://v3.wails.io/features/bindings/services/). Лицензионные материалы поставки собирает `scripts/package-notices.py`.

Модели, настоящие проекты, медиа, локальные отчёты, зависимости и результаты сборки в Git не входят.
