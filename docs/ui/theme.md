# Темы и визуальные значения

Источник токенов палитры для обеих тем — [theme-palette.ts](../../src/renderer/src/theme-palette.ts). Настройки темы и переключение режима находятся в [theme.tsx](../../src/renderer/src/theme.tsx). Используются MUI `ThemeProvider` и `CssBaseline`; режим `light`, `dark` или `system` сохраняется в `localStorage`, по умолчанию следует системной теме.

## Палитра

| Назначение | Токен MUI | Светлая тема | Тёмная тема |
| --- | --- | --- | --- |
| Основное действие и акцент | `primary.main` | `#1565c0` | `#7cc4ff` |
| Дополнительный акцент | `secondary.main` | `#ef6c00` | `#ffb74d` |
| Фон рабочей области | `background.default` | `#f4f6f8` | `#121417` |
| Поверхность карточки, панели, диалога | `background.paper` | `#ffffff` | `#1b1e23` |

В `theme-palette.ts` также явно зафиксированы цвета текста и разделителей, палитры состояний `success`, `warning`, `error`, `info`, оттенки `primary` и `secondary`, `common`, `grey`, а также цвета и прозрачность состояний `action`. Изначально они соответствуют значениям текущей темы и не зависят от изменения значений палитры MUI по умолчанию. Указывайте семантический токен темы (`text.primary`, `text.secondary`, `divider`, `action.hover` и т. п.) или `color` компонента MUI, а не копию цвета в `sx`.

Основные значения для текста и состояний:

| Токен | Светлая тема | Тёмная тема |
| --- | --- | --- |
| `text.primary` | `rgba(0, 0, 0, 0.87)` | `#ffffff` |
| `text.secondary` | `rgba(0, 0, 0, 0.6)` | `rgba(255, 255, 255, 0.7)` |
| `divider` | `rgba(0, 0, 0, 0.12)` | `rgba(255, 255, 255, 0.12)` |
| `success.main` | `#2e7d32` | `#66bb6a` |
| `warning.main` | `#b84a00` | `#ffa726` |
| `error.main` | `#d32f2f` | `#f44336` |
| `info.main` | `#0271b3` | `#29b6f6` |

Основные цвета состояний, `primary` и их оттенок `dark` (фон наведения contained-кнопки) держат 4.5:1 с `contrastText`, а `main` как текст — на `background.paper` и `background.default` обеих тем; это проверяет `theme-palette.test.ts`. `warning.light` остаётся светлым для подсветки поиска с тёмным текстом.

Зафиксированные оттенки и состояния палитры хранятся в `theme-palette.ts`. Некоторые цвета компонентов MUI, например фон `Alert`, вычисляются из токенов; обновление MUI может изменить их отображение, даже если значения токенов остались прежними. В медиапросмотре, canvas и отдельных существующих компонентах используются также локальные цвета. При изменении токена обновляйте этот файл и, если значение показано в таблицах выше, соответствующую таблицу. Проверяйте результат в светлой и тёмной темах, включая текст, состояния и контраст элементов управления.

Основной цвет выделяет акцентные действия и выбранное состояние. `secondary` — дополнительный акцент, а не обязательное оформление каждой второстепенной кнопки. Для кнопок добавления используйте `success`, для деструктивных действий — `error`, для акцентных действий — `primary`; конкретные правила и подтверждения описаны в [компоновке](layout.md#блоки-формы-и-кнопки). `success`, `warning`, `error` и `info` также обозначают соответствующие состояния; смысл должен быть понятен по тексту или значку, а не только по цвету. Проверяйте контраст текста и элементов управления в обеих темах; для цветной поверхности используйте подходящий контрастный текст из темы.

Не добавляйте локальную палитру для обычных страниц и не меняйте цвета темы ради одного блока. Изменение общей палитры — отдельное решение, затрагивающее оба режима и все экраны. Для изображений, видео и canvas допустимы специальные цвета, когда они необходимы самому содержимому; их также проверяют в обеих темах. В существующих шкалах и отдельных компонентах встречаются прямые цвета — это не дополнительная общая палитра.

## Размеры и типографика

- `shape.borderRadius = 8` px, `typography.fontSize = 13.5`; семейство шрифта и варианты типографики берутся из MUI по умолчанию.
- Кнопки по умолчанию без тени (`disableElevation`), `TextField` по умолчанию имеет `size="small"`.
- Используйте варианты `Typography`, а не произвольные размеры для каждого блока. Заголовок страницы должен выделяться сильнее заголовка секции; вспомогательные сведения оформляйте через `text.secondary` и подходящий вариант текста.
- Шкала MUI spacing по умолчанию — 8 px: `1` = 8 px, `1.5` = 12 px, `2` = 16 px, `3` = 24 px. Используйте её для обычных отступов: внутри тесной группы обычно `1`, внутри блока и между блоками `2`, у рабочей области оболочки `3`. Особая плотность монтажной шкалы или таблицы может отличаться по назначению.
- Моноширинный шрифт используйте для кодов, времени, путей, хешей и технического вывода, когда он улучшает чтение, а не для обычных заголовков и пояснений.
