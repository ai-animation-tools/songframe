# shot_status

Сводит статусы всех планов из первичных источников: реестр сцен, локальные комплекты в assets, очередь `plan/awaiting`, рабочие попытки в `plan/batches` и реестр работ. Использовать для списков `list=all|progress|completed`, выбора `scene=next` и проверки, можно ли готовить несколько планов одновременно. Файлы проекта не изменяет, к сервисам не обращается.

```sh
python3 -B tools/shot_status/shot_status.py
python3 -B tools/shot_status/shot_status.py --filter progress
python3 -B tools/shot_status/shot_status.py --next
python3 -B tools/shot_status/shot_status.py --json
python3 -B tools/shot_status/shot_status.py --independent M52 M53 M55
```

Статусы и этапы: `completed` — есть `assets/shots/Mxx/manifest.json`; `progress` — есть пакет очереди, попытка в `plan/batches` или отметка в реестре работ; `planned` — только постановка; `unknown` — файлы пакета повреждены или этап не определён. Для `progress` показывается фактический этап: из `attempt.json` при отправленной попытке, иначе из `stage` и `wait_reason` в `workflow.json`. Незавершённая проба или альтернативный пакет у готового плана показываются примечанием и не отменяют готовность.

`--next` выводит первый не готовый план в порядке монтажной шкалы и очередь ожидающих пакетов; выбор между ними делает пользователь. `--independent` сообщает конфликты партии: более поздний план наследует состояние после непустых `state_changes` более раннего плана из той же партии; при конфликте код возврата 1. Отдельно предупреждает о соседних по шкале планах: их стык можно сверить с фактическим кадром только после получения обоих, поэтому в одной партии они допустимы лишь при смене ракурса или намеренном монтажном пропуске, что подтверждает пользователь. Независимые планы можно готовить параллельно; отправка остаётся по одному запросу. `--json` даёт те же данные для приложения.

## Тесты

Четыре статуса, этапы из очереди и попытки, повреждённый пакет, примечание о пробе, кандидат next и конфликты партии на временной фикстуре проекта.

```sh
python3 -B tools/shot_status/test_shot_status.py
python3 -B tools/run_tests/run_tests.py --only test_shot_status
```

Тесты находятся рядом со скриптом; рабочие сцены не изменяют. Для полного набора — [run_tests](../run_tests/README.md).
