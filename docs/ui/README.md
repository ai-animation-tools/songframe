# Правила интерфейса SongFrame

Локальный стандарт Go/Wails-интерфейса адаптирован из правил SongFrame без изменения прежнего репозитория. Применяй [songframe-go-ui](../../dev-skills/songframe-go-ui/SKILL.md). При противоречии действуют [AGENTS.md](../../AGENTS.md) и явное актуальное поручение; предметные требования остаются у владельца соответствующего процесса. Документы описывают правила для затронутой задачи, а не утверждают соответствие всех экранов.

- [Компоновка и управление](layout.md): MUI, действия, автоматические состояния, формы и минимум окна.
- [Тема](theme.md): фактические токены обеих тем и правила контраста.
- [Структура](structure.md): renderer, Go-сервисы, Wails adapters и границы данных.
- [Тексты](texts.md): чистые доменные словари и владельцы исключений.
- [Storybook](storybook.md): актуальность историй, локальные модели и статическая браузерная проверка.

Приводи изменяемые элементы к правилам внутри задачи, не переделывая соседние процессы. Производственные согласования, сохранность оригиналов и платные запросы не подменяются хорошей вёрсткой. Минимальное и стартовое окно — **1320×860**, светлая и тёмная темы.
