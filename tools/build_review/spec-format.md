# Формат монтажной пробы

JSON для `--spec` в [build_review](README.md): ещё не принятый ролик вместо материала сцены, обрезка, скорость, удержания, переходы и звук. Команды, выбор материалов для `--shots` и условия запуска — в README.

## Контракт

```json
{
  "schema_version": 1,
  "shots": [
    {"scene": "M30"},
    {
      "scene": "M31",
      "path": "plan/batches/M31-attempt-01/original.mp4",
      "kind": "video",
      "source_start_frame": 30,
      "source_end_frame_exclusive": 174,
      "speed": "1.2",
      "hold_first_frames": 0,
      "hold_last_frames": 0
    },
    {"scene": "M32"}
  ],
  "transitions": [{"after": "M31", "type": "fade", "frames": 6}]
}
```

Пути `path` отсчитываются от **корня проекта** независимо от расположения JSON; абсолютные пути допустимы.

| Поле участка | Значение |
| --- | --- |
| `scene` | Существующий неповторяющийся Mxx; порядок в массиве задаёт порядок пробы |
| `path`, `kind` | Явный ролик или изображение, `video` либо `card`; без `path` материал выбирается из текущей сцены, как при `--shots` |
| `source_start_frame` | Начало включительно; по умолчанию 0 |
| `source_end_frame_exclusive` | Конец исключительно; по умолчанию начало плюс каноническая длина сцены |
| `speed` | Положительный множитель скорости, по умолчанию `1`; длительность движения округляется до ближайшего кадра, половина вверх |
| `hold_first_frames`, `hold_last_frames` | Явное удержание начала/конца, по умолчанию 0 |

**Все номера кадров относятся к сетке 30 FPS после преобразования входа**, а не к нативной сетке генерации. Для карточки начало 0, скорость 1, длительность задаёт конец. Размер приводится к 1920×1080 с сохранением пропорций и полями, без обрезки композиции. Выборка кадров при смене скорости — без интерполяции; дополнение последнего кадра ограничено округлением до заданной кадровой длины. Звук роликов в пробу не попадает.

`transitions`: без них — прямые склейки. Типы: `fade`, `fadeblack`, `fadewhite`, `dissolve`, `wipeleft`, `wiperight`. Переход — перекрытие соседей на `frames` кадров: он сокращает пробу и сдвигает последующие стыки; сумма перекрытий не может поглотить план целиком. Переходы, обрезку и скорость не подбирать без поручения.

`audio` (необязательно): `{"path":"source/track.mp3","start_frame":3300}`. По умолчанию начало берётся из реестра первой сцены; для непоследовательного набора сцен задать явно. Конец — по реальной длине пробы с учётом обработки и переходов. Округление конца песни к ближайшему кадру допускает дополнение аудио тишиной не более чем на половину кадра; более длинная нехватка останавливает сборку. Исходные сэмплы и начало музыки сохраняются, точный фильтр записывается в выходной рецепт `audio.filter`.

Результат: MP4 и одноимённый JSON с точными входами/хешами, обрезкой ОТ:ДО, скоростью и изменением длительности в секундах, удержаниями, фильтрами, переходами и кадрами стыков. Повтор при тех же входах и версии FFmpeg детерминирован; существующий MP4 или JSON не перезаписывается. Входы повторно сверяются после сборки; размер, FPS, число кадров и длительность звука проверяются до публикации. Это техническая проверка сборки, а не художественный анализ генерации. После принятия сцены параметры обработки переносятся в её локальный манифест; хранение и очистка проб — по [правилам assets](../../templates/project/assets/README.md#очистка-завершённых-видеопроб).
