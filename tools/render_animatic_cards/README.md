# render_animatic_cards

Служебный рендерер условных PNG-карточек из реестра и существующих референсов. Прямого CLI нет: карточки и их манифест обновляет [update_scene_views](../update_scene_views/README.md).

## Контракт

Входы: `plan/scenes.json`, изображения `source/`, шрифты DejaVu Sans (обычный и полужирный) из [fonts](fonts/) рядом с модулем и Pillow. Шрифты с лицензией ([fonts/LICENSE](fonts/LICENSE)) входят в комплекс и в обе поставки, путь вычисляется от расположения модуля, системные шрифты ОС не нужны; тот же шрифт использует [contact_sheet](../contact_sheet/README.md). `render_card` вызывается из общего обновления; отдельный скрипт для партии не нужен. Текст раскладывается движком Raqm, который Pillow подключает при наличии системной `libfribidi`; без неё Pillow переходит на базовую раскладку, глифы сдвигаются, и карточки образца и проектов расходятся с записанными хешами. Карточка не является сгенерированным опорным кадром или готовой сценой. Полную сборку выполняет [build_animatic](../build_animatic/README.md).

`render_keyframe_card(shot, target, project, keyframes, root, last_target)` рисует карточку плана, у которого все опоры пакета приняты: первая опора целиком на холсте, остальные полоской внизу, подпись «опоры приняты, видео не сгенерировано». При двух и более опорах последняя сохраняется отдельным PNG `Mxx.last.png` для растворения в сборке. Опоры вписываются без обрезки и растяжения.

`render_card(shot, target, project, references, root)` получает контекст явно: название из `plan/project.json`, референсы из `scenes.json`, корень для чтения изображений. Подпись миниатюры берётся из `short_name`, при отсутствии — из `name`; пометка `—` плана без референсов в карточку не попадает. У плана с `derived_from` к заголовку добавляется «• из Mxx» (план собирается из материала другого плана); заголовок обычного плана не меняется. Текст, не поместившийся в поле даже минимальным кеглем, сокращается по словам с многоточием: полный текст плана остаётся в монтажном списке и раскадровке. Глобальный реестр при импорте не загружается. После изменения проектных данных запускать общий обновитель; вручную заменять PNG не нужно.
