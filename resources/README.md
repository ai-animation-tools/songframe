# Иконка приложения

`icon-source.jpg` — исходное изображение пользователя без изменений. `icon.png` — квадратный PNG 1024×1024 с сохранёнными рисунком, пропорциями и тёмным фоном; используется AppImage, Linux-ярлыком и окном приложения. `icon.ico` содержит размеры 16, 24, 32, 48, 64, 128 и 256 пикселей и встраивается в Windows EXE.

Производные файлы подготовлены из исходного JPEG с уменьшением Lanczos. Перерисовка и удаление фона не применялись. При замене рисунка обновляйте оба формата.

Пути упаковки заданы в `electron-builder.yml`. PNG для окна копируется в `resources/icon.png` готового приложения; исходный JPEG и ICO отдельными файлами в поставку не включаются. Windows-ресурсы редактирует штатный `resedit` из electron-builder на Linux; это не запускает EXE и не добавляет цифровую подпись.
