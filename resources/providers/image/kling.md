# Kling: изображения

Платная генерация опорных кадров и обложки через [kling.ai](https://kling.ai/). Подключение, вход, собственный клиент, таблица цен, неизвестный исход отправки и отмена — общие с видео: [video/kling.md](../video/kling.md). Общий контракт провайдера — в [README](../README.md).

## Значения реестра

`paid: true`, `learnsPriceFromCharges: true`, `generationHistory` — та же галерея созданных работ. Цену изображения сервис заранее не сообщает никогда: интерфейс показывает её как сведения, а не предупреждение, и после первого списания запоминает цену такой же конфигурации.

## Возможности и параметры

- Команды `text_to_image` (без входа) и `image_to_image` (с референсами). Перед подготовкой приложение запрашивает актуальные объявления и проверяет пару command/model, аргументы, допустимые значения, обязательные слоты и их число. Предпочтения `generation.image` (модель, разрешение, пропорции, число вариантов, options) не считаются доказанными возможностями. Фактический аргумент разрешения может называться `img_resolution`.
- Начальные значения настроек: `2k`, `16:9`, один вариант. Несколько вариантов одной опоры возвращаются одним запросом; стоимость зависит от конфигурации. Наблюдение цены совпадает по модели, команде, полному JSON значимых параметров, числу результатов и входным слотам: цена T2I не переносится на I2I, другое разрешение или число вариантов.
- Ограничения видеонастроек (`generation.video`, пропорции конкретной видеомодели) к опорам не применяются; у изображений собственный снимок возможностей.

## Получение

Один запрос — одна опора `Kxx`: `image_request_choice` → оценка и подтверждение → отправка → `image_downloaded` → выбор кандидата. Формат оригинала (PNG/JPEG/WebP) определяется по байтам, включая адреса без расширения; оригинал сохраняется без перекодирования. Приоритет у явного адреса без логотипа; если его нет, используется исходный адрес результата — сам адрес не подтверждает отсутствие логотипа, а инструмент изображение не анализирует и логотипы не удаляет.

## Указания агенту

- Промпты опор передаются генератору без изменений; параметры запроса (разрешение, пропорции, число вариантов) берёт приложение из настроек проекта и объявлений модели, в промпте их не повторяй.
- Изображения кастинга из `allowedPaths` уходят референсами `image_to_image`; опишите в промпте опоры, что взять из каждого референса (внешность, транспорт, место), и какую позу и ракурс нужно получить.
